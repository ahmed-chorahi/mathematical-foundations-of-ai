# 00 — Prerequisites

This section contains only the mathematics that later sections assume: algebra, functions, exponents and logarithms, summation and set notation, and a little geometry and trigonometry. Nothing here is taught for its own sake — each topic reappears immediately in linear algebra, probability, or optimization.

## Before You Continue

You are ready for linear algebra (section 01) when you can:

- rearrange an equation to isolate any variable,
- evaluate $2^{-3}$, $\log_2 8$, and $e^{0}$ without hesitation,
- read $\sum_{i=1}^{n} x_i$ and say what it means for $n = 3$,
- find the distance between two points on a plane.
